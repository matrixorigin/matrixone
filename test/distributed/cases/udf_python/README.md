# Python UDF BVT cases

Put SQL cases that require the Python UDF worker in this directory. Each case
needs a matching `.result` file generated by `mo-tester`.

Run the complete Python UDF suite locally with:

```bash
python3 -m pip install -r pkg/udf/python/worker/requirements.txt
./optools/run_python_udf_bvt.sh "$(pwd)" /path/to/mo-tester
```

To create or refresh a result file after reviewing the expected output, start
the worker-enabled launch and use `mo-tester`'s `genrs` mode:

```bash
SKIP_JSTFU=true ./optools/run_bvt.sh . launch-with-python-udf-worker
cd /path/to/mo-tester
./run.sh -p /path/to/matrixone/test/distributed/cases/udf_python/example.sql -m genrs -g
```

The ordinary BVT jobs intentionally skip this directory because their launch
configuration does not start a Python worker. The dedicated Python UDF CI job
runs every case here with the worker and the pinned `pyarrow` dependency.
